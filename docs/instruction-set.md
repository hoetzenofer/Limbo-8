# Limbo-8 – Instruction Set

The tables are generated by `microcode/microcode.py` from `microcode/instructions.py`.

## 1. Notation

- Every instruction starts with the fetch step **T0** = `AB=PC · MEM→IR · PC_INC`. The tables show the steps after T0. **Cycles** include T0.
- 16-bit operands are little-endian: `JMP $1234` = `43 34 12`.

| Notation                                   | Meaning                                               |
| ------------------------------------------ | ----------------------------------------------------- |
| `AB=PC` / `X` / `SP` / `MAR`               | driver of the address bus                             |
| `source→destination`                       | data bus transfer, e.g. `MEM→A`                       |
| `ADD→A`, `AND→A`, `OR→A`, `XOR→A`, `SHR→A` | ALU result into A                                     |
| `ADD→–`                                    | ALU result onto the bus, nobody loads it (only flags) |
| `ALU_INV`, `CIN=0/1/C`                     | invert T, carry-in                                    |
| `FL_ZN`, `FL_C`                            | load flags Z/N, C                                     |
| `STEP_RST`                                 | last step, next instruction                           |
|                                            | write or SP load step (the address must not change)   |

## 2. Rules

- **Z and N** are set by everything that loads A or B, by all ALU instructions and by `INC`, `DEC`, `SHL`, `SHR`.
- **C** is set by `ADD`, `ADC`, `SUB`, `SBC`, `CMP` and `SHL`. After `SUB`/`CMP`, C = 1 means no borrow (A ≥ operand, unsigned).
- There is no `CLC`/`SEC`: `ADD #0` clears C, `CMP #0` sets it.
- Stores, `PUSH`, jumps and instructions that only change X leave the flags alone. `POP F` loads all flags.
- The stack lives at `$DF00–$DFFF` and grows downwards. SP points to the next free byte: `PUSH` writes, then decrements; `POP` increments, then reads.
- The first instruction of every program is `LDSP #$FF`.
- `$00` = `NOP`, `$FF` = `HLT`. All free opcodes act like `HLT`.

Bit fields:

- Load/store `0001 S R mm`: S = store, R = register B, mm = `#n` / `addr` / `[X]` / `[X+]`.
- Jumps `0100 0 p ff`: ff = Z / C / N / always, p = 1 jumps on 0.
- Stack `0101 P rrr`: P = pop, rrr = A / B / XL / XH / F.
- ALU `100 ooo mm`: ooo = operation, mm = `#n` / `addr` / `[X]` / `B`.
